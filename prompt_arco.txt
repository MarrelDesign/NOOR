CONTEXTO
========
Proyecto Noor. Repo ya inicializado con 10+ commits en main. Hay untracked files
(ruido: imágenes generadas, carpetas de producto, etc.). Ahora: limpiar, commit
final, y preparar para GitHub + Netlify.

TAREA
=====
1. Ver qué archivos están sin rastrear (git status)
2. Actualizar .gitignore para excluir el ruido (imágenes generadas, __pycache__,
   carpetas de "producto", etc.)
3. Hacer git add -A y verificar qué se va a commitear (git status nuevamente)
4. Si hay cambios reales en src/, index.html, package.json, etc., hacer un commit
   limpio con mensaje: "Clean: remove untracked files and finalize for deployment"
5. Si NO hay cambios reales (solo limpieza de .gitignore), no necesitas commit
6. Verificar que npm run build sigue funcionando
7. Resumen: estado del repo, qué se limpió, si hizo commit o no

PASO A PASO
===========

1. Estado actual
   cd ~/noor
   git status
   (Muestra archivos tracked/untracked y cambios)

2. Examina .gitignore (si existe)
   cat .gitignore
   (Si no existe, créalo. Si existe, añade las líneas que falten.)

3. Actualiza .gitignore para excluir ruido
   Asegúrate de que tenga:
   node_modules/
   dist/
   .env
   .DS_Store
   *.log
   __pycache__/
   *.pyo
   /producto/
   /collage/
   Gemini*
   *generated*
   .cache/

   Si algo falta:
   cat >> .gitignore << 'EOF'
   /producto/
   /collage/
   Gemini*
   *generated*
   EOF

4. Verifica .gitignore está en git
   git add .gitignore
   git status
   (Los archivos ruido ahora NO deben aparecer en "Changes to be committed", solo
    en "Untracked files ignored".)

5. Limpia cambios no deseados (si los hay)
   Si hay cambios en archivos rastreados que NO quieres:
   git checkout -- <archivo>

6. Verifica qué se va a commitear
   git status
   (Debe mostrar solo cambios reales de src/, index.html, etc. NO ruido.)

7. Commit (si hay cambios)
   Si git status muestra "nothing to commit", no hagas nada.
   Si hay cambios reales:
   git add -A
   git commit -m "Clean: finalize for Netlify deployment"

8. Verifica build
   npm run build
   (Debe terminar sin errores. Luego limpia: rm -rf dist)

9. Resumen
   git log --oneline -5
   git status
   (Todo debe estar limpio, main up-to-date.)

PASOS SIGUIENTES (manuales, fuera de aquí)
===========================================

A. Crea repo en GitHub:
   https://github.com/new
   - Nombre: noor
   - Privado o público (para portfolio, público)
   - NO inicies con README/gitignore (ya lo tienes)

B. Conecta tu repo local:
   git remote add origin https://github.com/TU_USUARIO/noor.git
   git branch -M main
   git push -u origin main
   (Necesitarás un token de GitHub: Settings > Developer settings > Personal access
    tokens > Tokens (classic) > Generate new token > repo full access.)

C. Conecta a Netlify:
   1. https://app.netlify.com > "New site from Git"
   2. Autoriza GitHub, selecciona repo "noor"
   3. Build settings (auto-detectados):
      - Build: npm run build
      - Publish: dist
   4. Deploy
   5. URL pública: https://noor-xxx.netlify.app (o tu dominio)

FIN
===
Cuando todo esté limpio y pusheado a GitHub, para aquí y te daré los pasos de
Netlify.
